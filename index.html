Then on your PC

  1. Move both files to the Downloads folder (USB cable, Google Drive, Nearby Share, anything).
  2. Both files are .gguf. If your phone saved them as data or without an extension, rename them to gemma3-4b.gguf (the big one) and gemma3-4b-vision.gguf (the small one). Renaming is only for tidiness: Xemn recognises the files by their size and checksum, whatever they are called.
  3. In the xemn-ai folder run python start_xemn.py. It finds the two files, checks them, moves them into Ollama and starts everything.
How to check the files are complete

Exact sizes: the model is 3,155,051,328 bytes, the vision part is 851,251,104 bytes. If a file is smaller, the download stopped early: download it again. Xemn also checks the SHA-256 and tells you if a file is damaged.
